# Manuscript-to-Lean map

Reference: [cloning.tex](cloning.tex). This map records statement correspondence, not merely import coverage. Names below are actual declarations; linked files contain their full hypotheses. The current build and axiom-audit evidence is recorded separately in [PROGRESS.md](../verification.html) and [verification/latest.json](../data/audit-summary.json).

The four main physical theorem families are instantiated for the constructed channels and actual CPTP competitors. The reconciliation covers all 27 named theorem, proposition, lemma and corollary statements, including their uniformity, support and rate requirements. Historical `*_of_compactWindowLAN` results and the generic assembly theorems in `Main.lean` remain conditional interfaces; they are not the final physical certificate.

## Conventions and objects

| Manuscript object | Lean object and convention |
|---|---|
| Root fidelity `F(ρ,σ)` | `PositiveTraceClass.rootFidelity`; no square unless `^ 2` is displayed. |
| Dimension `D ≥ 1` | Often encoded as `d+1`; projector statements commonly use rank `r` and dimension `r+k`. These offsets must be applied before comparing exponents. |
| Simple positive spectrum | `Cloning.SimpleSpectrum D`: positive, strictly decreasing, normalized eigenvalues. |
| All physical competitors | `Cloning.InfiniteTraceClass.QuantumChannel`; complete positivity and trace preservation are properties of the actual linear map. |
| Known/unknown finite-copy minimax | `Cloning.TensorCloning.knownSpectrumValue`, `unknownSpectrumValue`, built from `statePayoff`/`spectrumPayoff` and actual supremum/infimum. |
| Projectors and projector minimax | `Cloning.PhysicalFlatGrassmann.Projector r k` is a literal Hermitian idempotent of rank `r`; `minimaxValue` ranges over this family. |
| Prescribed output sizes | `m : ℕ → ℕ`, `m(n)/n → γ > 1`. `TensorCloningPrescribedLimits` and `PCTPrescribed*` handle initial indices with `m≤n` by exact restriction. |
| Unknown-spectrum regularity | `closure (interior (SimpleSpectrum.toAffine '' K)) = SimpleSpectrum.toAffine '' K` in the full trace-one affine hyperplane, not the relative interior of an arbitrary lower-dimensional set. |
| PCT error asymptotics | An iterated limit: fixed positive additional-copy ratio first, then that ratio tends to zero. Projector PCT uses liminf/limsup envelopes and does not assume a fixed-gain fidelity limit. |
